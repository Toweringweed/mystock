# 估值纪律

## 核心原则:用 2 年远期 PE 估值

**禁止仅用静态 PE 做判断**,因为:
- 周期股景气底部静态 PE 高(利润被压扁)
- 周期股景气顶部静态 PE 低(利润高峰)
- 静态 PE 会让你"在底部恐高,在顶部贪婪"

**必看指标:**
- 2026 年远期 PE(短期估值锚)
- 2027 年远期 PE(中期估值锚)
- PEG = 2 年远期 PE / 业绩复合增速

## 不同行业的估值锚位置

| 板块 | 2026 远期 PE 合理区间 | 估值方法 |
|---|---|---|
| 光模块龙头 | 25-35 倍 | 远期 PE + PEG |
| 算力芯片(海外链) | 25-30 倍 | 远期 PE + 对标英伟达 |
| 算力芯片(国产链) | 用 PS 估值 3-8 倍 | PS(亏损/微利) |
| 存储/接口芯片 | 25-35 倍(周期高点) | 远期 PE + 历史分位 |
| AI PCB | 20-30 倍 | 远期 PE |
| 半导体设备 | 30-40 倍(国产替代溢价) | PEG |
| IDC/液冷 | 25-35 倍(设备类) | EV/EBITDA(IDC 类) |
| 电力/储能 | 15-25 倍 | 远期 PE |

## 周期股专用估值方法

**周期不同阶段用不同指标:**

| 周期阶段 | 估值方法 | 原因 |
|---|---|---|
| 景气底部 | PB + 历史 PB 分位 | 利润不稳但资产可信 |
| 景气复苏 | 远期 PE 25-35 倍合理 | 利润开始恢复 |
| 景气加速 | PEG 0.5-1.0 合理 | 增速兑现中 |
| 景气顶部 | PE 历史分位 + 二阶导监控 | 警惕拐点 |

## 关键警戒规则

**规则 1:英伟达 PE 锚定**
当 A 股算力链龙头(光模块、AI PCB、AI 服务器代工)的 2 年远期 PE
显著高于英伟达同期远期 PE 时,即为"过度透支"信号。

参考:英伟达 2026 年远期 PE 大致 25-30 倍。

**规则 2:PEG 校验**
任何标的 PEG > 1.0 需要谨慎,> 1.5 应该减仓或回避。
例外:有真正长期叙事的龙头可放宽到 1.2。

**规则 3:历史 PE 分位**
- < 30% 分位:相对低估,机会大
- 30-70% 分位:中性
- > 70% 分位:警惕,需要"业绩超预期"才能继续上涨
- > 90% 分位:极度高估,主动减仓
