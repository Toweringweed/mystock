## 自然语言输出格式(默认 ✅ 优先使用)

按以下结构组织(必含 4 个增强模块):

1. **一句话结论**(看多/中性/看空 + 时间维度)
2. **近期股价情况**:当前价 / 5日 / 20日涨跌、MA 多空排列、量能、支撑压力位、技术信号
3. **六维度评分简述**(每维度 2-4 句 + 数据证据)
4. **估值详细分析**:
   - 静态(PE_TTM / PB / PS / ROE)
   - 远期(2026/2027 forward_pe + PEG)
   - 历史分位
   - SOTP 拆解(复杂公司必做)
   - 估值定性判断 + 触发再评估的具体阈值
5. **机构净利润预测与目标价表**(至少 2-3 家机构,DB + Web 双来源,含目标价空间)
6. **横向比较表**(至少 2 只可比标的,含远期 PE / 增速 / PEG / 目标价空间 / 业务差异)
7. **三大关键利好**
8. **三大关键风险**
9. **操作建议**(具体价格区间 + 仓位建议)
10. **重新评估触发条件**
11. **本次分析的不确定性**
12. **免责声明**

### 引用规范
- 数据库来源:`[DB]` 或省略
- Web 来源:`[Web:中金研报 2026-04-28]` 等(必须含信源 + 日期)
