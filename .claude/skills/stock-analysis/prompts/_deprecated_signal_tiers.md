# 信号分层规则

并非所有信号权重相等。决策时按以下分层处理。

## Tier 1 信号(决策级,权重 70%)

这些信号**直接决定**买卖判断,必须严肃对待:

| 信号 | 数据来源 | 评估频率 |
|---|---|---|
| 远期 PE 历史分位 | financials 表 | 每次分析必看 |
| 行业景气度方向 | 行业月度数据 | 每次分析必看 |
| 业绩兑现度 | 季报数据 | 季度更新 |
| 公司护城河变化 | 毛利率 + 市占率 | 季度跟踪 |

**Tier 1 判断不一致时,以"基本面"为最终依据**(估值再低,基本面破坏也要规避)。

## Tier 2 信号(参考级,权重 25%)

这些信号**优化择时**,但不主导决策:

| 信号 | 数据来源 | 用法 |
|---|---|---|
| 机构持仓变动 | 十大流通股东 | 季度对比 |
| 北上资金流向 | 日度资金流 | 短期情绪 |
| 龙虎榜 | 异动日数据 | 短期波段 |
| 技术形态 | daily_quotes | 择时辅助 |

**Tier 2 信号的解读规则:**
- 机构减持 ≠ 一定看空(可能是仓位再平衡或获利了结)
- 必须结合减持比例、减持人身份、估值位置综合判断
- 单一 Tier 2 信号**不构成**买卖理由

## Tier 3 信号(噪音级,权重 5%)

这些信号需**警惕反向**,共识强烈时反而要警觉:

| 信号 | 用法 |
|---|---|
| 媒体情绪 | 极度乐观时警觉(共识陷阱) |
| 社交热度 | 散户讨论度过高时警觉 |
| 卖方研报评级 | 全市场一致看多时警觉 |

## 综合权重计算

```
最终评分 = Tier1 信号分 × 0.70
        + Tier2 信号分 × 0.25
        + Tier3 信号分 × 0.05
```

注:Tier 3 即使是反向信号,权重也很低,主要起"提醒"作用。
